Add Mapper to ID group

1) Client Scope -> Create client scrope
Name: groups
Type: default

2) In the group scope created, go to the tab Mappers.
3) Click on Configure a new mapper
4) Select Group Membership
Name: groups
Token Claim Name : groups
Full group path OFF
SAVE

5) Go back to Clients -> guacamole (client created) -> Select Client scopes tab
6) click on Add client scope
Select the created scope you created in the previous steps.
